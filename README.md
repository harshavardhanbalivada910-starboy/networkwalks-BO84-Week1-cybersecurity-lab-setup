Week 1 Project: VirtualBox and Kali Linux Setup on macOS

Project Description

This project focuses on installing and configuring Oracle VirtualBox on macOS and setting up Kali Linux as a virtual machine. The objective is to understand virtualization and gain practical experience with Linux in a macOS environment.

Objectives

- Install Oracle VirtualBox on macOS.
- Identify the Mac processor architecture (Intel or Apple Silicon).
- Download the compatible Kali Linux image.
- Create and configure a virtual machine.
- Allocate RAM, CPU cores, and virtual storage.
- Install and boot Kali Linux successfully.
- Explore basic Linux terminal commands.

Tools and Technologies

- Host OS: macOS
- Virtualization Software: Oracle VirtualBox
- Guest OS: Kali Linux
- Architecture: Intel / Apple Silicon (depending on Mac model)

Learning Outcomes

- Understood virtualization concepts.
- Learned VirtualBox installation on macOS.
- Gained hands-on experience installing Kali Linux.
- Learned basic Linux commands and VM configuration.
- Understood the differences between Intel and Apple Silicon environments.
